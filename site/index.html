How it works

Scan, compose, sketch, render. Then the checks decide.

The skill teaches your coding agent how to read the repo, invent a visual metaphor and write plain-language copy. The vyo CLI prints the sheet and runs automated checks on the finished render.

  1. 1

    Scan

    Reads the codebase as text into facts.json: files, lines and imports. No network, no model, and your code is never run. Two scans of the same tree give the exact same file.

    npx vyo scan . --out vyo/app-facts.json
  2. 2

    Compose & draw

    Scaffolds a luminous poster spec for your chosen print style. Your agent draws a bespoke soft-lit SVG explaining the product, names each part in plain words, and marks the focal accent.

    npx vyo compose vyo/app-facts.json \
  --frame luminous --style obsidian \
  --repo . --out vyo/app-poster.json
  3. 3

    Sketch

    Produces a fast preview of the geometry and typography before the full optical pass, plus every check that needs no browser, so the agent fixes the drawing and words first.

    npx vyo sketch vyo/app-poster.json
  4. 4

    Render and check

    Prints the poster in headless Chromium to HTML, a 2× PNG, a thumbnail and a print-ready PDF, then measures the finished pixels. Any ✗ finding exits 1 and names the exact change to make.

    npx vyo render vyo/app-poster.json

Honest encoding

The silhouette is invented for the product; the strata and refraction underneath are driven straight from the scan.

Strata
Horizontal band heights equal each part's share of real source lines — never arbitrary stripes.
Imports
Cross-file imports between areas drive horizontal shear and chromatic fringe across the optical waterfall.
Accent
The focal area that defines the product, rendered as luminous circular beads or glowing iso-lines.

Automated checks

  • luminous-tonal checks luminance histogram richness and warns on flat clip-art SVGs.
  • luminous-accent verifies the accent core stands out cleanly without flooding the sheet.
  • luminous-sanctuary fails if bright artwork collides with the typography.
  • luminous-jargon rejects code jargon, file paths and placeholders in headline, legend and micro-type.

Install

Three commands in the project you want to explain.

  1. $ npm install --save-dev @litterthanlit/vyo
  2. $ npx vyo init
  3. $ npx playwright install chromium
  • init

    Copies the skill into .cursor/skills/vyo/ and .claude/skills/vyo/. Pass --cursor or --claude to choose one, or --codex to also point AGENTS.md at the skill.

  • Chromium

    Already have Chromium or Chrome? Set VYO_CHROMIUM to its path and skip the last command.

  • Node

    Node.js 20 or later.

  • Try it

    Without installing: run npx -y @litterthanlit/vyo init, and have the agent run npx -y @litterthanlit/vyo wherever the skill says npx vyo.

Then say this to your agent

“Analyze this repo and explain what it does as a vyo poster.”

or pick a medium: “Make a riso or contour poster for this codebase.”

The agent follows the skill, invents a visual metaphor from your code, and writes a 2× PNG, a thumbnail and a print-ready PDF into vyo/ at the project root.

What it reads

Nothing leaves your machine. The scan reads source files as text and runs only git, to read the latest commit, with hooks off. Dotfiles such as .env, hidden folders, tests, node_modules and build output are skipped.

Languages

JavaScript, TypeScript, Python and Agent Skills .md repositories get full structural detection. Go, Ruby, Rust, PHP, Java, Kotlin, Swift, C#, C and C++, Dart, Scala, Elixir, Lua and Zig are scanned and drawn by size and imports.
