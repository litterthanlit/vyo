# Abstract field mockups (throwaway)

Three takes on "the project painted as a field" for Hypher, each driven by `hypher-facts.json` (a scan of litterthanlit/hypher at 7e1ff3a) and built from the owner's references: the Durations identity (Public Records), Constellation of Complicity (BACC 2025), the Vorflux moth, and the earlier Portrait idea.

| Folder | Idea | Rule |
|---|---|---|
| `a-wave/` | Rows of part names bent into one wave that bleeds off the sheet | One row per 420 lines of each part, in tree order; the handoff part in the accent |
| `b-displace/` | One sentence per row, letter gaps opening into discs | One disc per major part, area by lines, pulled toward the parts it imports from |
| `c-portrait/` | The project's own identifiers at 3px, density drawing a diagonal sweep | Nine bands, one per part, height by share of lines, each filled with that part's identifiers |

Each folder has its own README with what was tried and the region kind the skill's engine would need. These are not the skill and are not checked by it. Regenerate with `node render.mjs` in each folder (needs Playwright and the fonts in `.cursor/skills/explain-app/tools/fonts/`).
